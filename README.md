## اجرا در Unity

ریشهٔ مخزن را در Unity Hub با **Unity 6000.6.3f1** باز کنید. پس از Import، از منوی `Nightshift > Open Game Scene` صحنه را باز کنید و **Play** را بزنید. فرمان `Nightshift > Validate Scene and Assets` اتصال Prefabها، منابع صوتی، ورودی و مدل‌های واردشده را بررسی می‌کند.

| کنترل | عملکرد |
| --- | --- |
| `A` و `D` یا فلش چپ و راست | تعویض یک خط |
| `W` یا فلش بالا | نیترو و شتاب |
| `S`، فلش پایین یا `Space` | ترمز |
| `Esc` یا `P` | توقف و ادامه |
| `M` یا دکمهٔ صدا | قطع یا وصل صدا |

مسیر با سرعت ۱۲۸ کیلومتر بر ساعت شروع می‌شود. سکه ۱۲۵ امتیاز، سبقت ۳۲ امتیاز و گالن حداکثر ۳۲ واحد سوخت می‌دهد. قلب‌های کمیاب از حدود کیلومتر ۱٫۱ ظاهر می‌شوند و یک جان ازدست‌رفته را برمی‌گردانند. شارژ نیترو ۲٫۵ ثانیه پس از رهاکردن کلید آغاز می‌شود.

برای بررسی شرط خودروی مانع ثابت و نور زیر بدنهٔ وابسته به سرعت، پیش از شروع **Course mode** را روشن کنید. اولین مانع ثابت در خط راست و حدود ۲۱۲ متری مسیر قرار دارد. ترافیک پشت سر آن فاصله را حفظ می‌کند و این حالت رکورد مستقل دارد.

## ویرایش در Inspector

| بخش | محل ویرایش |
| --- | --- |
| دوربین سوم‌شخص و پردازش تصویر | صحنهٔ `Assets/Scenes/Nightshift.unity`، آبجکت `Third-person Chase Camera` |
| نور ماه، نور مکمل، مه، Bloom و رنگ | بخش `Lighting` و فایل `Assets/Nightshift/Assets/Lighting/NightGrading.asset` |
| خودرو و چراغ‌ها، مانع ثابت، سکه، سوخت و قلب | `Assets/Nightshift/Assets/Prefabs` |
| چراغ‌های جاده و تونل، تابلوهای تونل و پل | همان پوشهٔ `Prefabs` |
| رنگ خودرو، جاده، تابلو و بازتاب چراغ | `Assets/Nightshift/Assets/Materials` و فهرست `NightMaterials.asset` |
| کلیدها و گیم‌پد | `Assets/Nightshift/Assets/Input/Nightshift.inputactions` |
| صدای موتور، موسیقی و صداهای آیتم‌ها | بخش `Audio` صحنه و `Assets/Nightshift/Assets/Audio` |

چهار مدل ترافیک و مدل فراری در `Assets/Nightshift/Resources/Nightshift` قرار دارند. هندسهٔ جاده و کوهستان، بازیافت قطعات، رفتار ترافیک، تشخیص برخورد، تغییرات امتیاز و منابع، HUD و جلوه‌های واکنشی در اسکریپت‌ها پیاده شده‌اند.

## تحویل دانشگاهی

- گزارش پروژه در [`Documentation/Report.pdf`](Documentation/Report.pdf) قرار دارد.
- برای ساخت بستهٔ اجرایی به Unity فعال و ماژول Build Support پلتفرم مقصد نیاز است. از منوی `Nightshift > Build Assignment ZIP…` نام، نام خانوادگی و شمارهٔ دانشجویی را وارد کنید و مقصد را مشخص کنید. ZIP شامل پوشهٔ خروجی بازی، گزارش و آدرس مخزن خواهد بود.
- در این بازنگری، ساختار فایل‌ها و ارجاع‌های دارایی‌ها خارج از Unity بررسی شده‌اند. اجرای Play Mode و خروجی بومی هنوز نیاز به بررسی در Editor دارند.
